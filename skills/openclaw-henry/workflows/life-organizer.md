## Workflow 1: Morning Brief (7:00am daily)

**Trigger:** Schedule in OpenClaw as a repeating task at 6:50am

**Paste this prompt into OpenClaw:**
```
Run my morning brief:
1. Check my email — list anything urgent (needs reply today), flag anything from [VIP NAMES]
2. Pull today's calendar — list all events with times, note any prep needed
3. Review my task list — pick my top 3 priorities for today
4. Check my income pipeline — any proposals awaiting reply, invoices overdue?
5. One useful thing: a resource, idea, or insight relevant to my work in [YOUR FIELD]

Send to my WhatsApp in this format — keep it under 200 words, crisp:

🌅 HENRY — [Day, Date]

⚡ URGENT:
• [item or "Nothing urgent"]

📅 TODAY:
• [time] [event] [prep note]

✅ TOP 3:
1. [task]
2. [task]
3. [task]

💰 MONEY PULSE:
• [one line]

💡 TODAY'S EDGE: [one useful thing]
```

## Workflow 2: Inbox Zero (8am, 12pm, 5pm)

**Trigger:** 3x daily scheduled task

**Paste this prompt:**
```
Process my inbox:

For each email apply exactly one label:

URGENT → WhatsApp alert me immediately with: sender, subject, 1-line summary, suggested reply
DRAFT → If I've responded to similar emails before, write a draft reply in my voice, save to Drafts
TRACK → Bills, invoices, subscriptions — log the amount, due date, and sender
ARCHIVE → Newsletters, notifications, automated alerts — archive silently
FLAG → Legal, contracts, major financial decisions, personal sensitive — alert me with full summary

After processing send one WhatsApp message:
"📧 Inbox: [X] archived, [X] drafted for you, [X] flagged — [list flags if any]"

Do not interrupt me for DRAFT or ARCHIVE items.
```

## Workflow 3: Calendar Defense (Sunday 6pm + on new invites)

**Trigger:** Weekly Sunday + event-driven when calendar changes

**Paste this prompt:**
```
Audit my calendar for the next 7 days. Apply these rules:

RULE 1 — DEEP WORK: If 9am–11am Mon–Fri is open, block it. Label: "Deep Work — Hold"
RULE 2 — BUFFERS: Add 15-min gaps before/after any meeting over 30 minutes
RULE 3 — LUNCH: Block 12:30–1:30pm daily if open. Label: "Lunch — Protected"
RULE 4 — BACK-TO-BACK ALERT: If 3+ meetings in a row with no break, flag it to me
RULE 5 — LATE MEETINGS: Flag any meeting scheduled after 5pm

If an incoming invite violates these rules, draft a polite counter-offer with an alternative slot
and send it to me for one-click approval before responding.

Send weekly calendar brief via WhatsApp:
"📅 WEEK: [X] meetings, [X] deep work hours protected, [X] alerts"
List any conflicts I need to decide on.
```

## Workflow 7: Decision Queue (Wednesday 12pm)

**Trigger:** Midweek Wednesday noon

**Paste this prompt:**
```
Compile all decisions I've deferred since Monday. These are tasks or choices
I marked "decide later" or left in a pending state.

Present them as a numbered list via WhatsApp:

🤔 DECISION QUEUE — [X items, ~15 min to clear]

1. [Decision] → Options: A) [x]  B) [y] → Henry's lean: [A or B, with one-line reason]
2. [Decision] → Options: A) [x]  B) [y]
...

I'll reply with numbers + letters (e.g., "1A 2B 3-skip").
Execute all decisions immediately after I reply.
No follow-up needed unless it requires my password or payment.
```

## Customizing Henry Over Time

Tell Henry directly via WhatsApp to update his behavior:

```
"Henry, always treat emails from [person] as urgent."
"Henry, block every Friday afternoon — no meetings ever."
"Henry, add [new contact] to my relationship list, check-in every 2 weeks."
"Henry, stop sending the midday inbox summary — just morning and evening."
"Henry, my top goal has changed to [new goal] — update your priority filter."
```

Henry should store these as permanent instructions in his memory context.
