# Henry: Income Generation Workflows

Ready-to-paste prompts for each income channel Henry can run.

---

## Income Channel 1: Freelance & Consulting Opportunities

### Setup Prompt (run once to initialize)
```
My professional background:
[PASTE 3–5 sentences about your skills, experience, and the type of work you do]

My target rate: $[X]/hr or $[X]/project minimum

My ideal client: [describe who you want to work with]

Sample past work: [link to portfolio or describe 2–3 past projects]

Save all of this as my professional profile. Use it whenever drafting proposals or responding to opportunities.
```

### Daily Monitoring Prompt (runs every morning)
```
Search for freelance opportunities matching my profile on:
- Upwork (search: [YOUR SKILL KEYWORDS])
- LinkedIn Jobs (remote, contract, [YOUR FIELD])
- Contra.com ([YOUR SPECIALTY])
- We Work Remotely if applicable

For each match above my minimum rate:
1. Save it to my opportunities list
2. Evaluate fit on a 1–10 scale against my profile
3. For anything scoring 7+: draft a proposal in my voice, referencing my background

Send me a WhatsApp alert:

💼 NEW OPPORTUNITIES — [Date]
• [Job title] at [Company] — $[rate] — Fit: [X/10] — Proposal drafted ✓
• [Job title] at [Company] — $[rate] — Fit: [X/10] — Needs your review

Drafted proposals are in my Drafts folder. Reply "send [number]" to submit.
```

### Follow-Up Prompt (runs every 3 days)
```
Check my sent proposals from the last 30 days.
For any proposal with no response after 3 days, draft a polite one-line follow-up.
For any proposal with no response after 7 days, mark as cold and archive.

Send summary:
"📋 Proposal pipeline: [X] pending, [X] followed up, [X] archived cold"
```

## Income Channel 2: Content & Digital Products

### Opportunity Research Prompt (weekly, Monday morning)
```
Research what people in [YOUR TOPIC/INDUSTRY] are asking about right now.

Check:
- Reddit: r/[relevant subreddit] — top posts from last 7 days
- Quora: [YOUR TOPIC] — most viewed questions this week
- Twitter/X: trending in [YOUR NICHE] this week
- Answer The Public or similar: common questions around [KEYWORD]

Find the 5 biggest unanswered questions or pain points.
For each one, evaluate:
- Audience size (how many people have this problem?)
- My ability to answer it (high/medium/low)
- Content format fit (article / short video / PDF guide / course)

Send via WhatsApp:

📝 CONTENT OPPORTUNITIES — [Week]

TOP 5 GAPS:
1. "[Question]" — Audience: [large/medium/small] — My fit: [H/M/L] — Format: [type]
2. ...

HENRY'S TOP PICK: [best opportunity + one-paragraph outline]
```

### Content-to-Product Pipeline Prompt
```
Look at my existing content (blog posts, notes, past work samples I've shared with you).
Identify anything that could be:
- Expanded into a paid guide (Gumroad, Lemon Squeezy)
- Turned into a template pack
- Packaged as a mini-course

For the best candidate, draft:
1. A product title and one-line description
2. A 5-point outline of what it would cover
3. A suggested price point based on comparable products

Send the brief for my review.
```

## Income Channel 3: Reselling / Arbitrage

### Setup Prompt (run once)
```
I'm interested in reselling in these categories: [e.g., electronics, tools, books, collectibles]

My buying criteria:
- Minimum profit margin: [X]%
- Maximum purchase price per item: $[X]
- Platforms I want to sell on: [eBay / Facebook Marketplace / other]

Save this as my reselling profile.
```

### Daily Deal Scanner Prompt
```
Scan these sources for items matching my reselling profile:
- Facebook Marketplace in [YOUR CITY] — search: [YOUR CATEGORIES]
- Craigslist [YOUR CITY] — search: [YOUR CATEGORIES]
- OfferUp if available

For each item found:
1. Search eBay "sold listings" for the same item to get realistic resale value
2. Calculate estimated profit margin
3. Flag anything with 30%+ margin

Send WhatsApp alert:
"🛒 [X] resell opportunities found. Best: [Item] — Buy $[X], Sell ~$[X], Margin [X]%"
```

## Income Channel 4: Local Services / Gig Work

### Platform Setup Prompt (run once per platform)
```
Help me set up a service listing on [TaskRabbit / Thumbtack / Craigslist].

My service: [DESCRIBE WHAT YOU OFFER]
My area: [CITY/ZIP]
My rate: $[X]/hr or $[X] flat

Draft a compelling service listing description (150 words max) that:
- Leads with the customer's problem
- States my experience and reliability
- Includes a clear call to action

Also draft responses to the 5 most common questions customers ask about [YOUR SERVICE].
Save all of this to my services profile.
```

### Inquiry Response Prompt (triggered by incoming messages)
```
When I receive a new inquiry for my [SERVICE] gig:
1. Check my calendar for available slots in the next 7 days
2. Draft a reply that: thanks them, confirms availability, asks 1–2 qualifying questions
3. Send me the draft for one-click approval

If the same person messages twice with no reply from me, send me a reminder.
```

## Income Channel 5: Passive Income Setup

### Affiliate Research Prompt (monthly)
```
Research affiliate programs that fit my content in [YOUR NICHE/TOPIC].

- At least 20% commission or $20+ per referral
- 30+ day cookie window
- Products I could genuinely recommend

Send a shortlist:

• [Program] — [Commission] — [Cookie] — Fit: [H/M/L] — Why: [reason]"

For the top 3, draft a one-paragraph "I use this" disclosure I could add to my content.
```

## Activating Henry for a New Income Mission

When you have a new income goal, tell Henry directly:

```
"Henry, new income mission:
Goal: $[X] in the next [30/60/90] days
Method I want to focus on: [freelance / content / reselling / gigs / passive]
My constraint: I have [X hours/week] available
Start tracking this as a goal and report progress weekly."
```

Henry will then:
1. Research the fastest path to that goal given your constraints
2. Set up monitoring for matching opportunities
3. Track progress weekly in the income report
4. Apply a Monte Carlo prediction to estimate probability of hitting the goal on time
