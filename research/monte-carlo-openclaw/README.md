# Monte Carlo Predictive Analysis: OpenClaw (ClawdBot) Future

## Overview

This directory contains a comprehensive Monte Carlo simulation and analysis predicting the future trajectory of **OpenClaw** (formerly ClawdBot/Moltbot) — the viral open-source AI personal assistant — across three time horizons and five scenarios.

## Contents

```
monte-carlo-openclaw/

├── slides/
│   └── SLIDE_DECK.md                 ← Presentation deck (15 slides)

    └── simulation_results.json       ← Raw output (generated by running simulation)
```

## Quick Start

### Read the Analysis
1. **Research Paper:** Open `paper/RESEARCH_PAPER.md` for the full analysis
2. **Slide Deck:** Open `slides/SLIDE_DECK.md` for the visual presentation

### Run the Simulation
```bash
cd simulation
python3 monte_carlo_openclaw.py
```
This runs 10,000 Monte Carlo simulations for each of 5 scenarios × 3 time horizons (150,000 total simulations) and outputs results to `data/simulation_results.json`.

### View the Slide Deck
The slide deck is in Markdown format compatible with:
- **Marp** (VS Code extension or CLI): `marp slides/SLIDE_DECK.md --html`
- **Slidev**: `slidev slides/SLIDE_DECK.md`
- **Deckset** (macOS): Open directly
- **reveal.js**: Import as Markdown

## Summary of Findings

| Scenario | Probability | 12-Month Stars | 12-Month Users | 12-Month MRR |
|---|---|---|---|---|
| S1: Hypergrowth | 10% | 680K | 1.2M | $9M/mo |
| S2: Strong Growth | 25% | 425K | 520K | $2.3M/mo |
| S3: Plateau (Base) | 35% | 206K | 215K | $260K/mo |
| S4: Security Crisis | 20% | 151K | 45K | $18K/mo |
| S5: Collapse | 10% | 115K | 8K | $800/mo |

**Weighted average at 12 months:** ~310K stars, ~340K users, ~$1.5M MRR

## Methodology

- 10,000 Monte Carlo simulations per scenario per time horizon
- Day-by-day simulation with Gaussian growth noise and Poisson security incidents
- Anchored to real observed data as of January 31, 2026
- Parameters derived from GitHub trending data, press coverage, and security assessments
